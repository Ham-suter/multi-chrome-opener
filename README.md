# Chrome Multi Opener

여러 Google Chrome 프로필에서 같은 URL을 한 번에 열 수 있는 Windows용 오픈소스 유틸리티

## 주요 기능

- Chrome 프로필 자동 감지
- 원하는 프로필 선택 후 동일 URL 실행
- 프로필 별칭 및 그룹 관리
- 프로필 검색
- 선택 상태 및 설정 저장
- 설치 없이 실행 가능한 Portable EXE

---

# English

Chrome Multi Opener is an open-source Windows utility for opening the same URL across multiple Google Chrome profiles.

## Features

- Automatic Chrome profile detection
- Open the same URL in selected profiles
- Profile aliases and groups
- Profile search
- Persistent settings and selections
- Portable EXE with no installation required
